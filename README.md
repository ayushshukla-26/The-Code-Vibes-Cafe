# ☕ The Code Vibes Cafe

**A Python-Based Cafe Management System**

Created by: Ayush Shukla

## 📌 About the Project
The Code Vibes Cafe is a Python-based cafe management application that helps manage cafe menus, customer orders, billing, discounts and order history.

## ✨ Features
- View complete cafe menu
- Add new food items
- Update item prices
- Delete menu items
- Place customer orders
- Select ice cream flavours
- Apply discount coupons
- Generate customer bills and receipts
- Save previous orders
- Store menu and order data using JSON files

## 🛠️ Technologies Used
- Python
- JSON
- File Handling

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python cafe.py
```

## 📂 Project Files
- `cafe.py` – Main Python application
- `menu.json` – Stores cafe menu information
- `orders.json` – Stores customer order history (generated when orders are saved)
